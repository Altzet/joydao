Полная картина проекта — документ `claude/00-START-HERE.md` в проекте claude.ai «Интервью» (Projects → project_read). Прочитать его в начале сессии. Ниже — то, без чего нельзя трогать код и сервер.

## Где что
- Сайт: **https://joydao.org** (старый joylao.duckdns.org — только 301-редирект, в командах не использовать). Адрес задаёт `WEBAPP_URL` в `/opt/joydao/.env`.
- Игра: `/nunu` (Telegram Mini App https://t.me/JOYDAO_bot/nunu). Обмен: `/obmen` (сайт + вкладка в игре). Правила `/rules`, статьи `/uchastok`, `/esli-to`.
- Боевой сервис — `app/pause.py` (имя историческое): подключает все роутеры. Игра — `static/nunu.html` (один файл) + `app/nunu.py`. Обмен — `app/obmen.py` + `static/obmen.html`. Общая шапка сайта — `landing.header()`, `landing.tg_js()`.
- Админка `/nunu/admin` (ключ `NUNU_ADMIN_KEY`): содержание игры — `app/nunu_admin.py` (черновик → «Публикация»); обмен, путь игрока, люди, рассылка, напоминания, страницы сайта, копия базы — `app/admin_more.py`, настройки в `admin_kv` (`x:<имя>`) действуют сразу.
- Меню игры: Карта · Сад · Удиви себя · Обмен · Настройки. «Мой участок» — кнопка на карточке «Твой остров» на карте.
- Сайт ↔ игра: что можно сделать на сайте, делается на сайте (вход виджетом Telegram, домен в @BotFather `/setdomain` = joydao.org); внутри Telegram страницы сайта открываются в той же игре с «← В игру».

## Сервер
- `89.167.102.2`, хост `dolf-bot` — **общий с DOLF, его не трогать**. Папка `/opt/joydao` — не git, файлы кладём curl'ом с GitHub по **полному хешу коммита** (ветку raw кэширует ~5 мин).
- systemd `joydao`, порт 8080 за nginx. Поднимается ~20–30 с — проверять циклом, не одной ранней проверкой.
- `main` на GitHub = то, что должно работать на сервере. Пользователь не программист: давать **одну готовую команду** с проверкой в конце.

Шаблон выкладки:
```bash
H=<полный хеш>; cd /opt/joydao && for f in <файлы>; do curl -fsSL "https://raw.githubusercontent.com/Altzet/joydao/$H/$f" -o "$f" || echo "ОШИБКА: $f"; done && systemctl restart joydao && for i in $(seq 30); do c=$(curl -s -o /dev/null -w "%{http_code}" https://joydao.org/nunu); [ "$c" = 200 ] && break; sleep 2; done; echo "игра: $c"
```
Правка только в `static/*.html` — без перезапуска.
